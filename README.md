# Rice Leaf Disease Detection 🌾

## Project Overview
Rice Leaf Disease Detection is a Deep Learning and Computer Vision project that classifies rice leaf images into three disease categories: Bacterial Leaf Blight, Brown Spot, and Leaf Smut.

The project explores image preprocessing, exploratory data analysis, Convolutional Neural Networks (CNN), and Transfer Learning using MobileNetV2. Data augmentation techniques are also implemented to improve model generalization and investigate their impact on classification performance.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy and Pandas
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Models Implemented
- Custom Convolutional Neural Network (CNN)
- MobileNetV2 with Transfer Learning

## Key Concepts
- Exploratory Data Analysis (EDA)
- Image preprocessing and normalization
- Train, validation and test splitting
- Transfer Learning
- Data Augmentation
- Model Training and Evaluation
- Confusion Matrix and Classification Report

## Disease Categories
1. Bacterial Leaf Blight
2. Brown Spot
3. Leaf Smut

## Project Objective
To explore and develop image classification models capable of identifying rice leaf diseases and compare their performance using different deep learning approaches and data augmentation techniques.
